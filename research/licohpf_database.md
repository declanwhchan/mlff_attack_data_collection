# LiCOHPF Database

[LiCOHPF database repository](https://github.com/gitliwq/LiCOHPF_database_1). The source repository associates its data with Li et al. (2025), [DOI: 10.1039/D5MH01343G](https://doi.org/10.1039/D5MH01343G).

The defensible publication use of this subset is a robustness benchmark on 20 related Li-C-O solid-electrolyte-interphase (SEI) configurations.
